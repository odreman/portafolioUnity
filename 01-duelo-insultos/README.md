# Duelo de Insultos 🗡️

Un duelo de insultos inspirado en el clásico **Monkey Island**, donde los jugadores se enfrentan en un combate por turnos respondiendo preguntas y realizando insultos creativos.

**[🎮 Jugar en itch.io](https://odreman.itch.io/duelo-insultos)**

---

## 📖 Sobre el Juego

Este juego recrea la mecánica icónica del duelo de insultos de Monkey Island, donde dos personajes se enfrentan en un combate verbal. El juego conserva el espíritu del original, utilizando las preguntas y respuestas clásicas del juego original.

## 🎮 Cómo Jugar

Una vez iniciado el juego, el turno se selecciona de forma aleatoria. En función de ello, deberás hacer y/o responder las preguntas. El juego está configurado para **tres asaltos**. Cada pregunta respondida correctamente suma un punto. Gana quien tenga la mayoría de puntos al final.

### Mecánicas Principales

- ⚔️ **Sistema de turnos aleatorio**: Al inicio se determina aleatoriamente quién comienza
- 🎯 **Tres asaltos**: El juego consta de tres rondas completas
- 📚 **Preguntas originales**: Utiliza las preguntas clásicas de Monkey Island
- 🏆 **Sistema de puntos**: Cada respuesta correcta suma un punto
- 👑 **Victoria**: Gana quien tenga la mayoría de puntos al finalizar

## 🛠️ Implementación Técnica

### Características Desarrolladas

- **Sistema de diálogos**: Implementación de un sistema de diálogo básico para mostrar las preguntas y respuestas
- **Carga de datos desde JSON**: Las preguntas y respuestas se cargan dinámicamente desde archivos JSON
- **Animaciones**: Escenas animadas utilizando estados y translación de objetos para mejorar la jugabilidad
- **Sistema de audio**: Incorporación de sonidos para incrementar la experiencia de juego
- **Simulación de pelea**: Sistema que refleja quién gana cada asalto y muestra el resultado final
- **Gestión de estados**: Control del flujo del juego y transiciones entre estados

### Tecnologías

- **Motor**: Unity 3D
- **Lenguaje**: C#
- **Formato de datos**: JSON
